## Проекты

### [Project Thessa](https://github.com/Mar2ianen/project-thessa)

Мейнтейнер основного репозитория — песочницы на Rust с физической симуляцией, заводами и аэрокосмической инженерией. В проекте занимаюсь:

- Процедурными крыльями и корпусами, аэродинамикой и управлением полётом.
- Сборкой аппаратов, кабинами, двигателями, топливом, энергоснабжением и тепловыми системами.
- Серверной симуляцией: разделением и стыковкой аппаратов, командами и исполнением манёвров для отдельных аппаратов.
- Материалами поверхности планет, сжатием и стримингом данных для GPU.

### [freshGram](https://github.com/Olyaham/freshGram)

Исправляю баги в этом форке Telegram Desktop на C++/Qt. Часть исправлений переношу из Telegram Desktop, часть касается ошибок самого форка.

Из последних правок: падения локального IPC, ошибки авторизации MTProto, ротация ключей секретных чатов, запрет отправки секретных сообщений сторонним переводчикам и отрисовка снимков сообщений.
